# Evaluation

Named evaluation configurations discoverable by `forgather eval test`. Each config selects a dataset and supplies sensible defaults so that evaluating a model requires only a model path — no dataset project path, template name, or script wrangling.

For full usage, flag reference, and output format, see [docs/guides/evaluating-models.md](../../docs/guides/evaluating-models.md).

## Projects

- **[common](./common/README.md)** - The built-in eval configs: TinyStories, C4, Open-Orca, OpenAssistant, and FineWeb-Edu-Dedup.
