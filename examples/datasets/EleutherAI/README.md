# WikiText Document Level

https://huggingface.co/datasets/EleutherAI/wikitext_document_level

> A modified version of the WikiText language modeling dataset that returns complete Wikipedia pages instead of line-by-line text. It contains over 100 million tokens extracted from verified Good and Featured articles on Wikipedia, with significantly larger vocabulary and longer documents compared to Penn Treebank, making it well-suited for models leveraging long-term dependencies.
