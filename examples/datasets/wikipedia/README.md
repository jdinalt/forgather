# Wikipedia

https://huggingface.co/datasets/wikimedia/wikipedia

> A comprehensive multilingual dataset containing Wikipedia articles across 323 languages from the Wikimedia Foundation, sourced from November 2023. Suitable for language modeling and masked language modeling tasks; the largest subsets are English (6.41M rows), German (2.85M rows), and French (2.56M rows).
