# Samantha

https://huggingface.co/datasets/QuixiAI/samantha-data

> A conversational dataset featuring Samantha, an AI assistant trained in philosophy, psychology, and personal relationships who aims to be a friend and companion. The dataset includes diverse conversation types (random, advice, philosophy, therapy, jokes, math, and more) generated using OpenAI's API.

See also Eric Hartford's introduction: https://erichartford.com/meet-samantha

## Configurations

- [samantha.yaml](./templatelib/configs/samantha.yaml) Samantha, one conversation per example
- [samantha-packed.yaml](./templatelib/configs/samantha-packed.yaml) Samantha with sequence packing
