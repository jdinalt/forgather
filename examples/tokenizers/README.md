# Tokenizer Examples

This directory contains examples of different tokenizer configurations and usage patterns in Forgather.

## Projects

- **[tiny_stories_bpe/](./tiny_stories_bpe/README.md)** - A BPE tokenizer trained on the TinyStories dataset.
- **[wikitext/](./wikitext/README.md)** - A BPE tokenizer trained on the Wikitext dataset.


For CLI usage with tokenizer projects, see **[docs/guides/working-with-tokenizer-projects.md](../../docs/guides/working-with-tokenizer-projects.md)**.
